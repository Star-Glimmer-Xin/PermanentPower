# PermanentPower

**简体中文** | [English](README.en.md)

《杀戮尖塔 2》mod：能力牌永久生效

## 主要功能

- 使用能力牌后记录并将其从卡组中移除。在每场战斗开始时，获得记录的能力牌的效果
- 允许为全体卡牌/mod卡牌/每张卡牌分别设置启用与否

## 安装

前置要求：

- 《杀戮尖塔 2》`0.111.0`
- [RitsuLib](https://github.com/BAKAOLC/STS2-RitsuLib) `0.5.20` 或更高版本

把 `PermanentPower.dll` 和 `PermanentPower.json` 放进游戏目录下的 `mods/PermanentPower/`：

```
Slay the Spire 2/
  mods/
    PermanentPower/
      PermanentPower.dll
      PermanentPower.json
```

首次启动会问是否启用 mod，选是之后重启一次。
